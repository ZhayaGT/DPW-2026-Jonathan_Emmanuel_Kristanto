# Wireframe — Jobsheet 4

## Rancangan Fitur yang Belum Dikoding

Dokumen ini berisi rancangan fitur-fitur yang akan diimplementasikan pada pekerjaan berikutnya.

## 📋 Fitur yang Dirancang

### 1. Halaman Pencarian Buku
- Navigasi ke halaman pencarian buku
- Input pencarian berdasarkan judul, penulis, atau genre
- Hasil pencarian ditampilkan dalam tabel responsif

### 2. Halaman Detail Buku
- Tampilan detail lengkap setiap buku
- Informasi: judul, penulis, penerbit, tahun, ISBN, deskripsi
- Tombol pinjam/kembali buku

### 3. Halaman Peminjaman
- Daftar buku yang sedang dipinjam
- Formulir peminjaman baru
- Status peminjaman (dikembalikan / belum dikembalikan)

### 4. Dashboard Admin
- Ringkasan statistik yang lebih lengkap
- Grafik visualisasi data buku dan anggota
- Notifikasi untuk buku yang jatuh tempo

### 5. Sistem Autentikasi
- Halaman login untuk admin dan anggota
- Role-based access control
- Logout dan session management

## 🎨 Desain UI

- Skema warna: Ungu (#8E7CD8) dan Biru (#9bbcff)
- Layout mobile-first dengan responsive design
- Navbar dengan hamburger menu untuk perangkat mobile
- Kartu statistik dengan CSS Grid

## 📝 Catatan

Fitur-fitur di atas masih dalam tahap rancangan. Implementasi coding akan dilakukan pada jobsheet berikutnya.
